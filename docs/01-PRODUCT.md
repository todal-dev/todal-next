# 📋 제품 기획서

> **Todal** = Todo + Calendar | 할일 관리와 시간 시각화를 하나로

---

## 🎯 핵심 컨셉

**"할일 풀 → 드래그 → 캘린더 일정화"**

- **좌측**: 할일 리스트 (카테고리별 정리)
- **우측**: 주간 캘린더 (시간 블록으로 시각화)
- **드래그앤드롭**: 할일을 캘린더로 끌어다 놓으면 일정으로 변환

---

## ✨ 핵심 가치

| 문제점 | Todal의 해결책 |
|--------|---------------|
| 할일만 나열하면 언제 할지 모호함 | 캘린더에 배치하여 시간 확보 |
| 구글 캘린더는 할일 관리가 약함 | 할일 풀에서 체계적으로 관리 후 일정화 |
| 계획은 세우지만 실행이 안됨 | 시간 블록으로 시각화하여 실행력 UP |

## 📋 Phase 1 기능 명세 (MVP)

### 1. 할일 관리
- ✅ **할일 추가/수정/삭제**: 인라인 입력, Enter로 빠른 추가
- ✅ **체크박스**: 완료/미완료 토글
- ✅ **카테고리 라벨**: 색상으로 구분
- ✅ **서브 할일**: 계층 구조 지원
- ✅ **드래그 정렬**: 순서 변경

### 2. 캘린더 통합
- ✅ **주간 뷰**: 월~일 7일 표시
- ✅ **월간 뷰**: 미니 캘린더
- ✅ **시간 블록**: 0시~24시 타임라인
- ✅ **드래그앤드롭**: 할일 → 캘린더
- ✅ **시간 조정**: 드래그로 늘림/줄임
- ✅ **날짜 이동**: 다른 날짜로 이동

### 3. 카테고리 시스템
- ✅ **카테고리 생성/수정/삭제**
- ✅ **색상 선택**: 10가지 프리셋
- ✅ **순서 변경**: 드래그로 정렬
- ✅ **할일 필터링**: 카테고리별 보기

### 4. 반복 일정
- ✅ **반복 규칙**: 매일, 매주, 매월
- ✅ **요일 선택**: 월~일 다중 선택
- ✅ **반복 수정**: 이후 모두 / 특정 날짜만
- ✅ **반복 삭제**: 이후 모두 삭제
- ✅ **일반 일정 변환**: 반복 → 일반

### 5. 구글 캘린더 연동 (개발 중)
- 🔄 **OAuth 로그인**: Google 계정 연동
- 🔄 **양방향 동기화**: Todal ↔ Google Calendar
- 🔄 **실시간 반영**: 변경 사항 자동 업데이트

### 6. 인증 시스템
- ✅ **이메일 로그인**: Supabase Auth
- ✅ **회원가입**: 이메일 인증
- ✅ **로그아웃**

## 📅 Phase 2 기능 (성장 트래킹)

### 대시보드
- 📊 **카테고리별 시간 분배**: 주간/월간 그래프
- 📈 **완료율 추이**: 날짜별 완료/미완료 통계
- 🔥 **루틴 히트맵**: GitHub 스타일 달성률 표시
- 📄 **월간 리포트**: 자동 생성 요약

### 목표 관리
- 🎯 **카테고리별 목표 설정**: 주간/월간 목표 시간
- 📊 **달성률 표시**: 진행도 %
- 💪 **동기부여**: 목표 달성 시 축하 메시지

### 기록 탐색
- 🔍 **날짜/카테고리 필터**: 과거 기록 검색
- ⏱️ **타임라인 히스토리**: 시간순 활동 내역

## 🎯 타겟 사용자

### Primary
- 📚 **학생/취준생**: 공부 시간 관리, 루틴 형성
- 💼 **프리랜서/개발자**: 프로젝트 관리, 시간 트래킹
- 🎯 **자기계발러**: 습관 형성, 성장 기록

### Use Case
```
1. 아침에 오늘 할 일을 좌측에 쭉 적는다
2. 각 할일을 캘린더에 드래그하여 시간 배치
3. 하루 종일 캘린더 보면서 실행
4. 완료된 할일 체크
5. 저녁에 오늘 달성도 확인
```
