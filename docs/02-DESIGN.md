# 🎨 디자인 가이드

> Todal의 모든 UI/UX 디자인 원칙과 스타일 가이드

---

## 🦦 브랜드 아이덴티티

**Todal = 수달처럼 귀엽고 영리한 생산성 도구**

수달은 물 위에서 즐겁게 놀면서도 조개를 깨는 도구를 사용할 줄 아는 영리한 동물입니다.
Todal은 수달처럼 **재미있으면서도 똑똑한 일정 관리 경험**을 제공합니다.

### 브랜드 키워드
- 🦦 **귀여움** (Cute): 친근하고 부담없는 UI
- 💚 **자연스러움** (Natural): 유기적이고 부드러운 형태
- 🌊 **흐름** (Flow): 매끄럽고 유연한 인터랙션
- ⚡ **영리함** (Smart): 효율적이고 직관적인 기능

---

## 🎯 디자인 철학

**"Playfully Minimal & Naturally Functional"**

- **친근함**: 수달처럼 귀엽고 다가가기 쉬운 디자인
- **미니멀**: 깔끔하지만 따뜻한 느낌의 UI
- **자연스러움**: 둥글고 부드러운 형태, 유기적인 움직임
- **기능성**: 재미있으면서도 실용적인 경험

### 1. 할일 아이템

```

테두리:    없음
완료 시:   텍스트 Gray 400, 취소선
           완료 애니메이션: 체크 후 살짝 튕기는 효과
```

### 2. 캘린더 블록

```

호버 시:   살짝 위로 올라가는 효과 (translateY -2px)
```

## ✨ 애니메이션

**수달처럼 부드럽고 귀여운 움직임**

### 트랜지션

```
빠름:     150ms cubic-bezier(0.4, 0, 0.2, 1)
기본:     250ms cubic-bezier(0.4, 0, 0.2, 1)
느림:     350ms cubic-bezier(0.4, 0, 0.2, 1)
바운스:   400ms cubic-bezier(0.34, 1.56, 0.64, 1)  // 통통 튀는 느낌
```

### 주요 애니메이션

| 액션 | 효과 | 시간 | 느낌 |
|------|------|------|------|
| **호버** | 배경색 변화 + 살짝 띄움 | 200ms | 수달이 물 위에 떠오르듯 |
| **버튼 클릭** | Scale 1.02 → 0.98 → 1.0 | 250ms | 통통 튀는 느낌 |
| **드래그 시작** | 그림자 증가 + 살짝 회전 | 200ms | 수달이 조개를 집듯 |
| **완료 체크** | 바운스 애니메이션 | 400ms | 귀여운 통통 튐 |
| **페이지 전환** | 페이드 + 슬라이드 | 300ms | 물 위를 미끄러지듯 |
| **로딩** | 수달 꼬리 흔들기 스피너 | 1s 반복 | 기다리는 동안도 즐겁게 |

### 특별 효과

**수달 이스터에그**: 
- 연속 5개 할일 완료 시 → 수달 애니메이션 🦦
- 주간 목표 달성 시 → 수달 박수 이모지 표시

## 🦦 수달 마스코트 & 비주얼

### 마스코트 "토달이"

**캐릭터 특징**:
- 귀여운 수달 캐릭터
- 조개(일정)를 들고 있는 모습
- 둥글둥글한 형태
- 친근한 표정

### 사용처

**로고**:
- 헤더 왼쪽 상단
- 수달 실루엣 + "Todal" 워드마크
- 크기: 32x32px (아이콘), 로고타입 병행

**빈 상태 (Empty State)**:
```
상황: 할일이 없을 때
이미지: 수달이 물 위에 떠있는 모습
메시지: "오늘은 여유롭게~ 🦦"

상황: 검색 결과 없음
이미지: 수달이 물속을 둘러보는 모습
메시지: "찾으시는 할일이 없네요"

상황: 카테고리 없음
이미지: 수달이 조개를 찾는 모습
메시지: "카테고리를 만들어보세요!"
```

**로딩 스피너**:
- 수달이 조개 위에서 빙글빙글 도는 애니메이션
- 또는 물결 위를 헤엄치는 애니메이션

**성취 배지**:
- 🦦 할일 완료 시 수달 스티커
- 🎉 주간 목표 달성 시 수달 축하 애니메이션
- ⭐ 연속 달성 시 수달 별 뱃지

### 일러스트 스타일

```
스타일:    심플한 라인 아트 + 솔리드 컬러
색상:      Primary Green 계열
선 굵기:   2-3px (부드럽고 귀여운 느낌)

```
